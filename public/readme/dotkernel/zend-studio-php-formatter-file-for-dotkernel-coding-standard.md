# Zend Studio PHP Formatter file for DotKernel coding standard.

An XML file is provided for download, ready to be imported into Zend Studio, version 9.x. This file follows DotKernel's coding standard.

## Installation steps

1. Unzip the file.
2. Go to Zend Studio -> Preferences -> PHP -> Code Style -> Formatter.
3. Import the XML file.
