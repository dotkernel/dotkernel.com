# Zend Framework 1 End-of-Life

## TL;DR

Zend Framework 1 has officially entered End-of-Life (EOL) status now that Zend Framework 3 has been released.
Security updates for Zend Framework 1 continued only until 28 September 2016, three months after the announcement.

The End-of-Life (EOL) term was just announced.
Only up until Sept. 28, 2016, will Zend Framework 1 receive security updates.

"With the release of Zend Framework 3, it's time to halt development on Zend Framework 1.
As such, we hereby announce that Zend Framework 1 reaches its End of Life (EOL) three months from today, on 28 September 2016."

Read the [official announcement](https://framework.zend.com/blog/2016-06-28-zf1-eol.html).

## FAQ

**Q: What does EOL mean for Zend Framework 1?**
A: EOL stands for End-of-Life, meaning Zend Framework 1 has reached the end of its official support and development lifecycle.

**Q: Until when did Zend Framework 1 keep receiving security updates?**
A: Only up until 28 September 2016, three months after the EOL announcement was made.

**Q: Why was Zend Framework 1 being discontinued?**
A: Because Zend Framework 3 had been released, and it was time to halt development on Zend Framework 1.

**Q: Where was this announced?**
A: In an official Zend Framework blog post announcing that Zend Framework 1 reaches its End of Life (EOL) on 28 September 2016.
