# Codelobster PHP Edition - Free PHP, HTML, CSS, JavaScript editor (IDE)

## TL;DR

Codelobster PHP Edition is a free, lightweight IDE that highlights and autocompletes mixed PHP, HTML, CSS, and JavaScript code, including HTML5 and CSS3.
It also bundles an HTML/CSS inspector, a PHP debugger, an SQL manager, FTP support, and a portable mode that needs no installation.
On top of that, it ships plugins for popular CMS platforms and PHP frameworks such as Drupal, Joomla, CakePHP, CodeIgniter, Symfony, Yii, WordPress, and Smarty.

## Free PHP, HTML, CSS, JavaScript Editor (IDE) - Codelobster PHP Edition

For valuable work on creation of sites you need a good comfortable editor necessarily.
There are many requiring paid products for this purpose, but we would like to select free of charge very functional and at the same time of simple in the use editor - [Codelobster PHP Edition](http://www.codelobster.com/).

## FAQ

**Q: What kind of code highlighting does Codelobster PHP Edition support?**
A: It highlights code depending on its type, even within a mixed file, so HTML, PHP and Javascript sections are each highlighted according to their own language, with a choice of color schemes including those of popular IDEs.

**Q: What frameworks and CMS does Codelobster PHP Edition have plugins for?**
A: There are plugins for the Drupal and Joomla CMS, the CakePHP, CodeIgniter, Symfony and Yii PHP frameworks, the JQuery JavaScript library, the WordPress blogging engine, and the Smarty template engine.

**Q: What other tools does the editor include besides autocompletion and highlighting?**
A: It includes an HTML/CSS inspector similar to Firebug, context help (F1 opens documentation for the current tag, attribute or function), a PHP debugger for incremental execution with variable watching, an SQL manager for database operations, FTP support for working directly on a remote server, and a portable option that requires no installation.
